# AEJaCA - https://www.aejaca.com/
# Full crawl allowed, no staging paths.
#
# Query strings are intentionally NOT disallowed. The only parameters the site
# uses (?tab=, ?category=, ?co2mode=) are real in-page navigation linked from
# our own menus, and every page emits a canonical pointing at the clean path,
# so Google consolidates them instead of indexing duplicates. Blocking them
# only hid internally linked URLs from the crawler.
#
# UWAGA PRZY EDYCJI. Robot stosuje DOKLADNIE JEDNA grupe: te z najbardziej
# pasujaca nazwa User-agent, i ignoruje wszystkie pozostale, w tym `*`.
# Kazda nowa regula musi wiec zostac powtorzona w KAZDEJ grupie ponizej.
# Regula dopisana wylacznie do `*` nie obowiazuje zadnego z wymienionych botow.
# Tak wlasnie `Disallow: /admin/` przez jakis czas nie obowiazywal Googlebota.
